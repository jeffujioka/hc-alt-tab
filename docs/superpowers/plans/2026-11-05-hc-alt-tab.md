# hc-alt-tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Alt-Tab-style Switcher and Quick toggle for the Herdr desktop app that walk the 5 most recently visited Terminals across all Spaces and Machines.

**Architecture:** Two mods. `hc-alt-tab-recorder` lives in a zero-size layout block, records Visits (1 s dwell) into `shared("hc-alt-tab.recent")`, and owns Quick toggle (`cmd-f5`). `hc-alt-tab` is the Switcher overlay opened by `cmd-f4`, cycled through a `mod:hc-alt-tab` keys section, committed on Cmd release. All decisions about the list live in one pure module, `src/recent.js`, copied into both mod folders by the sync script and unit-tested with Bun. An installer applies and reverts the `keys.json` and layout edits.

**Tech Stack:** Herdr app mod runtime (plain JS ES2022, `gpui-kit`, `gpui-base`, `herdr` modules; no build step), Bun 1.4 (`bun test`, scripts), `herdr-app` CLI (`check`, `do`, `status`).

**Spec:** `docs/superpowers/specs/2026-11-05-hc-alt-tab-design.md` (read its Constraints and Results first). Terms: `GLOSSARY.md`. ADR: `docs/adr/0001-recorder-in-cloned-layouts.md`. Mod API reference on this machine: `~/.config/herdr-app/AGENTS.md`, `herdr.d.ts`, `gpui-kit.d.ts`; example overlay with focus + keys: `~/.config/herdr-app/mods/confirm/main.js`; program icon drawing: `~/.config/herdr-app/mods/agents/main.js:74`.

## Global Constraints

- Recent list: at most **5** Entries, newest first, all Machines together, persisted in `shared("hc-alt-tab.recent")`.
- Visit = same place focused for **1000 ms**; Switcher/Quick-toggle switches and the place current when `cmd-f4`/`cmd-f5` is pressed are Visits immediately.
- Entry key = Terminal address (`t13`, `bs/t13`). Places without a Terminal (mod panes, nothing focused) are never Entries.
- "Previous place" = newest Entry whose key ≠ the current place's key.
- Entries whose Terminal is gone drop out; Entries on a Machine whose `machines()` layout is `"unavailable"` stay, dimmed and unselectable.
- Keys: global `cmd-f4` → `mod.open:hc-alt-tab`; global `cmd-f5` → `hc-alt-tab-recorder.toggle`; section `mod:hc-alt-tab`: `cmd-f4` → `hc-alt-tab.next`, `cmd-shift-f4` → `hc-alt-tab.prev`. No other existing binding changes.
- Switch = `run("pane.focus", { terminal: address })` (spike-proven for local and remote, incl. inactive Tabs).
- Recording block: `{"id":"hc-alt-tab-recorder","type":"block","size":{"px":0},"resizable":false,"content":{"mod":"hc-alt-tab-recorder"}}` appended to the layout root's `children`. Never `"hidden"` (a hidden block never starts).
- Recorded layouts: `main-alt-tab` (clone of `main` via `herdr-app do layout.clone '{"name":"main","as":"main-alt-tab"}'`), `my-layout`, `mission-control`, `mission-control-classic`. Never edit `main`, `terminals`, `win98` (shipped, replaced on start).
- Mods are installed by **copy** (`rsync`) into `~/.config/herdr-app/mods/`, never symlink (symlinks don't hot-reload).
- Never `cx.notify()` from a timer unless the mod's own view changed; never `setShared` inside `render()`.
- Every mod change ends with `herdr-app check ~/.config/herdr-app/mods/<name>` passing.

## Review Focus

1. **Quick tap of `cmd-f4`**: Cmd released before the overlay takes focus → no `on_modifiers_changed` arrives; the person expects to land on the previous place, not a Switcher stuck open. Task 5 commits on the first key/modifier event showing `platform: false`, and also on `enter`; the real-key acceptance in Task 6 pins the tap.
2. **Entry's Terminal ended between Visit and switch**: expect it absent from the Switcher and skipped by Quick toggle, never an error toast. Pinned by `prune` tests (Task 1) and used on every read (Tasks 4, 5).
3. **Remote Machine offline**: expect its Entries visible but dimmed, not selectable, and Quick toggle to skip to the newest selectable previous place. Pinned by `previousPlace` offline test (Task 1).
4. **Fast passing-through (F2/F3 stepping, `alt-hjkl`)**: expect no Visits for places held < 1000 ms. Pinned by dwell tests (Task 3).
5. **Re-running the installer / uninstalling**: expect idempotence (no duplicate blocks or bindings) and a clean revert that leaves unrelated bindings and blocks untouched. Pinned by installer transform tests (Task 2).

## File Structure

```
hc-alt-tab/
  package.json                     bun test script only
  src/recent.js                    pure Recent-list logic (no herdr imports)
  src/dwell.js                     pure dwell tracker
  src/store.js                     herdr-backed list access shared by both mods (readList, writeVisit, offlineMachines)
  src/install-lib.js               pure keys.json / layout JSON transforms
  test/recent.test.js
  test/dwell.test.js
  test/install-lib.test.js
  mods/hc-alt-tab-recorder/{main.js,mod.json}
  mods/hc-alt-tab/{main.js,mod.json}
  scripts/sync.sh                  rsync mods/* + src/{recent,dwell,store}.js into ~/.config/herdr-app/mods/<mod>/
  scripts/install.js               sync, clone main-alt-tab, add blocks, add keys, switch layout
  scripts/uninstall.js             reverse of install (keeps main-alt-tab file unless --purge)
  README.md                        install, uninstall, keys, limits
```

Mods import the shared modules as `./recent.js`, `./dwell.js`, `./store.js` (copied in by `sync.sh`; relative imports are supported, see `mods/git-graph/main.js:3`). `store.js` imports from `"herdr"`, so it is not unit-tested under Bun; it holds only reads/writes, all decisions live in `recent.js`.

### Task 1: Recent-list logic

**Files:**
- Create: `package.json`, `src/recent.js`, `test/recent.test.js`, `.gitignore`

**Interfaces:**
- Produces (all pure, exported from `src/recent.js`):
  - `type Entry = { terminal: string, space: string, tab: string, pane: string | null, at: number }`
  - `MAX_ENTRIES = 5`, `SHARED_KEY = "hc-alt-tab.recent"`
  - `machineOf(address: string): string | null` — text before the first `/`, else `null`.
  - `placeOf(focused: {space,tab,pane,terminal} | null, now: number): Entry | null` — `null` when `focused` or `focused.terminal` is null.
  - `recordVisit(list: Entry[], entry: Entry): Entry[]` — entry first, older copy of same `terminal` removed, capped at `MAX_ENTRIES`. Does not mutate input.
  - `prune(list: Entry[], live: Set<string>, offline: Set<string>): Entry[]` — keeps an Entry if `live.has(terminal)` or `offline.has(machineOf(terminal))`.
  - `isSelectable(entry: Entry, offline: Set<string>): boolean`
  - `previousPlace(list: Entry[], currentTerminal: string | null, offline: Set<string>): Entry | null` — first Entry with `terminal !== currentTerminal` that is selectable.

### Task 2: Installer transforms and scripts

**Files:**
- Create: `src/install-lib.js`, `test/install-lib.test.js`, `scripts/sync.sh`, `scripts/install.js`, `scripts/uninstall.js`

**Interfaces:**
- Produces (pure, `src/install-lib.js`):
  - `BINDINGS = { global: { "cmd-f4": "mod.open:hc-alt-tab", "cmd-f5": "hc-alt-tab-recorder.toggle" }, "mod:hc-alt-tab": { "cmd-f4": "hc-alt-tab.next", "cmd-shift-f4": "hc-alt-tab.prev" } }`
  - `RECORDER_BLOCK` = the exact block from Global Constraints.
  - `RECORDED_LAYOUTS = ["main-alt-tab", "my-layout", "mission-control", "mission-control-classic"]`
  - `addBindings(keys: object): { keys: object, conflicts: string[] }` — adds every binding; a key already bound to a *different* action is left as is and reported in `conflicts` as `"<section> <key>"`.
  - `removeBindings(keys: object): object` — removes only keys whose value equals ours; drops `mod:hc-alt-tab` if it becomes empty.
  - `addRecorderBlock(layout: object): object` — appends `RECORDER_BLOCK` to `layout.children` unless a child with id `hc-alt-tab-recorder` exists.
  - `removeRecorderBlock(layout: object): object`
- `scripts/sync.sh`: for each `mods/<m>/`, `rsync -a --delete --exclude recent.js --exclude dwell.js --exclude store.js mods/<m>/ ~/.config/herdr-app/mods/<m>/`, then copy `src/recent.js`, `src/dwell.js`, `src/store.js` into that folder, then `herdr-app check` it; exit non-zero on any failure. Honors `HERDR_APP_HOME`.
- `scripts/install.js` (Bun): runs `sync.sh`; backs up `keys.json` and each touched layout to `<file>.hc-alt-tab.bak` (first install only); `herdr-app do layout.clone '{"name":"main","as":"main-alt-tab"}'` only if `layouts/main-alt-tab.json` is absent; applies `addRecorderBlock` to each existing `RECORDED_LAYOUTS` file and `addBindings` to `keys.json`; prints conflicts; `herdr-app do layout.switch '{"name":"main-alt-tab"}'`.
- `scripts/uninstall.js`: `layout.switch` to `main` if `main-alt-tab` is shown; `removeBindings`; `removeRecorderBlock` on each layout; removes both mod folders; deletes `layouts/main-alt-tab.json` only with `--purge`.
